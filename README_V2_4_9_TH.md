- หน้าหลักเหลือปุ่ม ค้นหา DSP และ บันทึก DSP
- เอา BLE MONITOR / OEM PROTOCOL / ACTUATOR LAB / HCI ANALYZER / MASTER PACKET LAB ออกจากหน้าหลัก
- เอาสถานะ protocol ยาวออกจากหน้าหลัก

- คง Master Android/Bluetooth Volume ที่ใช้งานได้
- คง CH1-CH7 Fader และ +/- 1 dB
- เมนูหลัก: MAIN / EQ / CROSSOVER / DELAY / MIXER / PRESET / SETTINGS
- เวอร์ชัน 2.4.9
